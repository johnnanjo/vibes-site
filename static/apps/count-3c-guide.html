スリークッション デジタルカウントの使い方

モニターに映して、テンキーだけで操作するカウントです。得点・交代・残り秒数・選手の名前まで、テンキーで入れられます。

用意するもの

パソコンで使う方法と、タブレットで使う方法があります。おすすめはパソコンです。カウント自体は無料です。

A. パソコンで使う（おすすめ）

もの選び方
パソコンWindows・Mac・Chromebook のどれでも使えます。HDMIの差し込み口があるものが楽です。ブラウザは Chrome か Edge を使います。
モニターHDMI入力がある横長（16:9）のもの。解像度はフルHD（1920×1080）で足ります。家庭用のテレビでも使えます。大きさは下の表を見てください。
HDMIケーブルパソコンからモニターまで届く長さ。5m以内が安心です。
無線テンキーUSBレシーバー式（2.4GHz）が、差すだけで使えて簡単です。BackSpace キーが付いているものを選びます。
電池テンキー用。予備も用意しておきます。
インターネット最初に1回開く時に必要です。そのあとは、なくても使えます。
HDMIの差し込み口がないパソコンの場合「USB-C → HDMI 変換アダプタ」を足します。USB-Cの口が映像出力に対応しているか、パソコンの説明書で確かめてください。

B. タブレットで使う

もの選び方
タブレット映像を外に出せる機種が必要です。iPad は対応しています。Android は機種によります。Fire タブレットは多くが出せません。
変換アダプタUSB-C の iPad・Android は「USB-C → HDMI」。Lightning の iPad は「Lightning → HDMI」。
無線テンキーBluetooth式を選びます。USBレシーバー式は、タブレットにそのまま差せません。
モニター・HDMIケーブルパソコンの場合と同じです。
iPad の画面についてiPad は画面の形がモニターと違うため、モニターの左右に黒い帯が出ることがあります。

モニターの大きさの目安

選手がどのくらい離れた所から見るかで決めます。迷ったら 32型 がおすすめです。

見る距離おすすめ残り秒数の数字の高さ
〜3m（台のすぐそば）24〜27型約6〜7cm
3〜5m（台の向こう側から）32〜43型約8〜11cm
5m以上（広い店・観客も見る）43〜55型約11〜14cm

数字の高さは、全画面にした時の計算上の大きさです。選手の名前は数字より小さいので、名前も離れて読みたい時は、ひとつ大きいサイズを選びます。置く高さは、目線から少し上が見やすいです。

A. パソコンの場合

  1. モニターを置いて、電源を入れる選手から見やすい場所に置きます。
  2. HDMIケーブルでパソコンとモニターをつなぐ両方の「HDMI」と書いてある口に差します。
  3. モニターの入力を「HDMI」に切り替えるモニターのリモコンか本体の「入力切替」ボタンを押します。パソコンの画面が映れば成功です。
  4. 映らない時は、パソコン側で切り替えるWindows は Windows キーを押しながら P を押し、「複製」を選びます。パソコンとモニターに同じ画面が出ます。
  5. テンキーをつなぐテンキーに電池を入れて電源を入れ、付属のUSBレシーバーをパソコンに差します。数秒で使えるようになります。
  6. カウントを開くChrome か Edge で vibesbilliards.com/pages/count-3c を開きます。
  7. 全画面にするキーボードの F を押します。テンキーの + を押して、点が入れば準備完了です。

B. タブレットの場合

  1. 変換アダプタをタブレットに差すアダプタにHDMIケーブルを差し、反対側をモニターに差します。
  2. モニターの入力を「HDMI」に切り替えるタブレットと同じ画面がモニターに映ります。
  3. テンキーをBluetoothでつなぐタブレットの「設定」→「Bluetooth」を開きます。テンキーのペアリングボタンを押し、一覧に出たテンキーの名前を押します。
  4. カウントを開くブラウザで vibesbilliards.com/pages/count-3c を開きます。
  5. ホーム画面に追加するブラウザのメニューから「ホーム画面に追加」を選びます。次からは、そのアイコンから開くと全画面で使えます。

使う前に確かめること

確かめることやり方
テンキーの数字が効くか効かない時は NumLock を1回押します。
日本語入力がオフか画面右下が「あ」の時は、半角/全角 キーで「A」にします。
音が出るか* で残り秒数を動かし、残り10秒で音が鳴るか確かめます。鳴らない時は、パソコンとモニターの音量を上げます。
電源パソコン・タブレットは充電器につないでおきます。カウントを開いている間は、画面は自動で消えません。
テンキーが届くか無線は10mほど届きますが、間に物があると弱くなります。使う場所から押して確かめます。

試合の流れ

上から順に押していけば、1試合ができます。

  1. 選手を登録する名前と持ち点を入れます。くわしくは下の「選手の登録」へ。
    ..
  2. 練習タイマーを使う（使う時だけ）試合前に − を押すと開きます。+ で開始、Enter で閉じます。
    −
  3. 残り秒数を始める（使う時だけ）はじめは40秒です。残り10秒と0秒で音が鳴ります。
    *
  4. 当たったら1点当たるたびに1回。まん中の RUN が増えます。
    +
  5. 外したら交代RUN の点が得点に入り、相手の番になります。0点の時もそのまま押します。
    Enter
  6. まちがえたら、もどす交代のあとでも、ひとつずつ前にもどせます。
    BackSpace
  7. 持ち点に届いたら試合終了GAME OVER と結果が出ます。Enter で次の試合（選手の登録）へ進みます。
    Enter
後攻の裏撞きについて先攻が先に持ち点に届いても、後攻がそのイニングを撞いてから試合終了になります。いらない場合は、設定の「EQUALIZING INNING」を OFF にします。

ネットなし・タブレットで使う

インターネットがない場所で使う

  1. ネットにつながる場所で、一度カウントを開きます。
  2. 次からは、ネットがなくても同じページが開きます。

得点・残り秒数・練習タイマー・登録した選手は、ネットなしで使えます。漢字の候補とスマホからの操作は、ネットが必要です。

タブレットをモニターにつなぐ

  1. タブレットとモニターを、変換アダプタとHDMIケーブルでつなぎます。
  2. 無線のテンキーをタブレットにつなぎます。
  3. カウントを開きます。使用中は画面が消えません。

映像を出せないタブレットもあります。買う前に機種を確かめてください。

スマホ・タブレットから操作する画面右上の「REMOTE」を押すと6桁のコードが出ます。スマホで カウントのリモコン を開き、コードを入れると操作できます。

困ったとき

キーを押しても動かない

画面を一度クリックしてから押してください。テンキーの数字が効かない時は NumLock を押します。日本語入力がオン（「あ」）の時は、半角（「A」）に切り替えます。

点を入れすぎた・交代をまちがえた

BackSpace を押すと、ひとつずつ前にもどります。

残り秒数が動かない

* を押すと始まります。設定の「SHOT CLOCK SECONDS」が 0 の時は動きません。

音が鳴らない

パソコンとモニターの音量を確かめてください。設定の「SOUND」が OFF の時は鳴りません。

ページを閉じてしまった

もう一度開くと、試合の続きから始まります。得点は消えません。

画面を大きくしたい

F を押すと全画面になります。
