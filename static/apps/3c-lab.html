スリークッションを、これから楽しみたい人へ。

ルールはシンプル、でも奥が深い。まずは「取り口」と呼ばれる形を、配置カードと辞典で知るところから。慣れてきたら、厚みや回転の基礎理論、狙う場所を数字で出すシステム計算へ進みましょう。

スリークッションって、どんなゲーム？

1

球は3つだけ自分の球（手球）が1つ、的になる球（的球）が2つ。ポケット（穴）はありません。

2

3回クッションに入れて当てる手球を撞いて、2つ目の的球に当たるまでに、クッションに3回以上入れると1点です。

3

当たれば、続けて撞ける外したら相手と交代。先に決めた点数に届いた人の勝ちです。

配置カード　__POSN__の配置

実戦でよく出る配置を、カードにまとめました。カードをえらぶと、軌道の図・撞点・厚み・ヒネリ・強さと、実戦の注意点が出ます。★を付けた配置は「マイ帳面」に残り、あとでまとめて見られます。

図は、厚み・撞点・ヒネリから球の動きを計算して描いた模式図です。実際の台では、ラシャやクッションの状態、撞く強さで軌道が変わります。数字は目安としてお使いください。

システム計算・早見表

クッションのポイント（ダイヤモンド）に数字をふって、狙う場所を計算で出す方法です。数字は目安で、台の状態や撞き方で変わります。

SYSTEM 01

ファイブ＆ハーフFive & Half System

裏回し・空クッションの基本となる、最重要のシステムです。

計算式

1クッション目の狙い目 ＝ 手球の出発値 − 3クッション目の到達値

数値マップ

手球の出発値1クッション目3クッション目

自動計算
実戦の補正ポイント
  • 標準の撞点は「順ヒネリ（2〜3チップ）」。
  • 手球の数値が 5（50）を超える深い角度（6〜8）になる場合は、クッションの食い込みにより短く（手前に）出やすいため、狙い目から 0.3〜0.5 ほど引く（厚く／深く入れる）補正が必要。
  • ラシャが新品で滑る台では伸びやすく、湿気や古いラシャでは短くなるため、1クッション目で基準の補正値を測ること。
SYSTEM 02

プラスシステムPlus System

短クッション側から長クッションへ入れる空クッションや、切り返し・ダブルレールの計算に使うシステムです。長クッション → 短クッション → 長クッションの順に入ります。

計算式

3クッション目の到達値 ＝ 手球の出発値 ＋ 1クッション目の狙い値
（1クッション目の狙い値 ＝ 目標到達値 − 手球の出発値）

数値マップ

手球の出発値1クッション目3クッション目

自動計算
実戦の補正ポイント
  • 基本の撞点とストローク：上の撞点（フォロー気味）＋順ヒネリ2チップ（2時または10時）が基本。押し出さず、自然な転がりで撞く。
  • 引きの補正（マイナス補正）：手球と1クッション目が近い場合や、手球の出発値が大きい（30〜40付近）場合は、カーブが出やすいため、狙い値を 2〜5 小さく狙う。
  • 台の状態の補正：ラシャが新しい（滑る）台や、クッションの反発が強い台では伸びるため 3〜5 小さく、重い台では 2〜3 大きめに狙う。
SYSTEM 03

短・長・短システムShort-Long-Short／バイアングル

短クッション → 長クッション → 短クッションの順に入れて切り返す、「短・長・短」ルートの標準の計算システムです。

計算式

3クッション目の到達値 ＝ 手球の出発値 − 1クッション目の狙い値
（1クッション目の狙い値 ＝ 手球の出発値 − 目標到達値）

数値マップ

手球の出発値1クッション目3クッション目

自動計算
実戦の補正ポイント
  • 基本の撞点：順ヒネリ2〜3チップ、高さは中心〜やや上。スピードを殺さず、スムーズに振り抜く。
  • 入る角度による伸びの補正：1クッション目の狙い値が大きい（30〜40付近＝浅い角度で入る）場合は、クッションの反発で2クッション目からあとが伸びやすいため、計算値より 2〜3 小さく狙う。
  • キス（衝突）を避ける：的球が2クッション目〜3クッション目の近くにある場合は、ヒネリを増やしてスピードを上げるか、厚みを調整して手球の軌道をずらす。

基礎理論

システムの数字を使う前に知っておきたい、球の動きの土台です。初球のならべ方から、厚み・回転・クッションの性質・空クッションの考え方まで、順番にまとめました。図はすべて考え方を示す目安です。

基礎 01

初球とゲームの流れ

ゲームは決まったならべ方から始まります。最初の1球だけは、赤い球に先に当てる決まりです。

初球のならべ方

自分の手球相手の手球赤球

おぼえておくこと
  • 赤球は奥のスポット、相手の手球は手前のスポットに置きます。自分の手球は、その左右どちらかのとなりに置きます。
  • 初球は、赤球に先に当てます。2球目からは、どちらの的球から当ててもかまいません。
  • 2つ目の的球に当たるまでに、手球がクッションに3回以上入っていれば得点です。当たれば続けて撞けます。
基礎 02

厚み的球にどれだけ重ねて当てるか

手球を的球にどれだけ重ねて当てるかを「厚み」と呼びます。厚みで、的球の進む向きと、2つの球に分かれる勢いが決まります。

厚みを動かしてみる
考え方
  • 的球は、当たった瞬間の「2つの球の中心を結んだ線」の向きへ進みます。
  • 厚く当てるほど、的球はまっすぐ速く走り、手球は勢いを失います。
  • 薄く当てるほど、的球はゆっくり横へ動き、手球は勢いを残して走ります。スリークッションで手球を長く走らせたいときは、薄めの厚みが基本です。
  • 半分の厚み（1/2）は、目で合わせやすい基準です。迷ったら、まず1/2からどちらへずらすかを考えます。
基礎 03

撞点と回転押し・引き・ヒネリ

手球のどこを撞くか（撞点）で、回転が変わります。上下は的球に当たったあとの進み方、左右はクッションに入ったあとの出方を変えます。

撞点をえらぶ
順ヒネリと逆ヒネリ

  • クッションに入ったあと、手球が進む方向へ転がる向きの回転が「順ヒネリ」、その反対が「逆ヒネリ」です。
  • クッションに向かって右へ進むなら、右ヒネリが順ヒネリです。左へ進むなら、左ヒネリが順ヒネリです。
  • 撞点を中心からずらす幅は「チップ」（タップ1個ぶん）で数えます。ずらすほど回転は増えますが、撞き損じも増えます。
基礎 04

クッションの特性入った角度と出る角度

クッションは、いつも同じ角度で跳ね返すわけではありません。撞く強さと台の状態で、出る角度が変わります。

強さをかえてみる

出方が変わる条件
条件出方
強く撞くクッションに食い込み、短く（立って）出る
弱く撞く長く（寝て）出る
新しくて滑るラシャ伸びやすい（長く出る）
古いラシャ・湿気が多い日短くなりやすい
順ヒネリ長く出て、勢いが残る
逆ヒネリ短く出て、勢いが落ちる
  • ヒネリは、1つ目のクッションでいちばん強く効きます。2つ目、3つ目と進むほど、効き方は小さくなります。
  • 同じ台でも日によって出方が変わります。撞きはじめに基準の球を1つ撞いて、その日の台を確かめましょう。
基礎 05

空クッションの考え方鏡にうつして狙う

クッションを先に使って当てるときは、クッションを鏡だと考えます。鏡の向こうにうつった的球へまっすぐ撞く、というのが基本の考え方です。

1クッションの狙い点を計算
考え方
  • 狙い点は、横の間隔を「手球の距離：的球の距離」に分けた場所です。クッションに近い球のほうへ寄ります。
  • この計算は、ヒネリなし・ふつうの強さのときの目安です。強く撞けば短く、順ヒネリなら長く出るぶんを足し引きします。
  • 2クッション、3クッションと増えても、鏡にうつす考え方は同じです。ただし回数が増えるほどずれが大きくなるため、実戦ではシステムの数字と組み合わせて使います。
基礎 06

ストロークとルーティン、システムと感覚

数字が合っていても、撞き方が毎回ちがうと球は同じ場所へ行きません。同じ手順で、同じように撞くことが、いちばんの土台です。

ストローク
  • キューはできるだけ水平に、まっすぐ出します。
  • 撞いたあとも顔と体を動かさず、キューを前へ送ります。
  • 強さは3段階（弱い・ふつう・強い）を決めておき、まず「ふつう」を安定させます。
撞く前のルーティン
  1. 立ったまま、取り口・厚み・撞点・強さを決めます。
  2. 決めてから構えます。構えてから迷ったら、いったん立ち直します。
  3. 素振りを同じ回数おこない、最後に一度止めてから撞きます。
システムと感覚
  • システムは「基準の線」を出す道具です。答えそのものではありません。
  • 基準からのずれ（台の状態、強さ、ヒネリの量）を合わせるのが感覚です。
  • はじめは数字どおりに撞いて結果を見て、どれだけずれたかをおぼえる。そのくり返しで、感覚が育ちます。
